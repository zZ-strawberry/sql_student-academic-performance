# 数据库对象与测试数据速查

## 1. 连接信息

| 项目 | 值 |
|---|---|
| 数据库名 | `student_score_mgmt` |
| 字符集 / 排序规则 | `utf8mb4` / `utf8mb4_0900_ai_ci` |
| 存储引擎 | InnoDB |
| 默认端口 | 3306（本机实验实例使用 3307） |
| 测试账号 | `root`（请按本机环境修改） |

## 2. 表清单

| 表名 | 中文名称 | 主键 | 记录数 |
|---|---|---|---:|
| `department` | 院系表 | `dept_id` | 3 |
| `teacher` | 教师表 | `teacher_id` | 6 |
| `classes` | 班级表 | `class_id` | 4 |
| `student` | 学生表 | `student_id` | 22 |
| `course` | 课程表 | `course_id` | 8 |
| `score` | 成绩表 | `(student_id, course_id)` | 105 |
| `score_audit` | 成绩审计表 | `audit_id` | 初始 0 |

### 2.1 主要外键

| 外键 | 引用 |
|---|---|
| `teacher.dept_id` | `department.dept_id` |
| `classes.dept_id` | `department.dept_id` |
| `student.class_id` | `classes.class_id` |
| `course.teacher_id` | `teacher.teacher_id` |
| `score.student_id` | `student.student_id` |
| `score.course_id` | `course.course_id` |

### 2.2 成绩表计算规则

- 总评成绩 = 平时成绩 × 30% + 期末成绩 × 70%；由 `trg_score_bi_calc`、`trg_score_bu_calc` 自动计算。
- 绩点由 `fn_grade_point` 换算：90 及以上 4.00，60 以下 0.00。
- 成绩修改由 `trg_score_au_audit` 写入 `score_audit`。
- `CHECK` 约束再次校验总评公式，防止绕过触发器直接写入不一致数据。

## 3. 视图

| 视图 | 作用 |
|---|---|
| `v_student_score_detail` | 学生成绩明细（学生、班级、院系、课程、教师、成绩） |
| `v_student_grade_summary` | 学生课程数、学分、加权绩点、挂科数 |
| `v_course_score_analysis` | 课程平均分、最高/最低分、及格率、优秀率 |
| `v_class_score_ranking` | 班级内按平均分排名 |
| `v_failed_student_courses` | 不及格学生、课程和分差 |

## 4. 存储过程与函数

| 名称 | 类型 | 说明 |
|---|---|---|
| `sp_save_score` | PROCEDURE | 按学号、课程代码录入或修改成绩，事务提交/回滚 |
| `sp_class_report` | PROCEDURE | 返回班级概览和学生排名两个结果集 |
| `fn_grade_point` | FUNCTION | 总评成绩到绩点的换算 |

调用示例：

```sql
CALL sp_save_score('2023001', 'C001', 80.0, 85.0, @code, @message);
SELECT @code, @message;
CALL sp_class_report('计算机2301班');
```

## 5. 触发器

| 触发器 | 时机 | 事件 | 作用 |
|---|---|---|---|
| `trg_score_bi_calc` | BEFORE | INSERT | 校验成绩与学籍，计算总评、绩点 |
| `trg_score_bu_calc` | BEFORE | UPDATE | 修改成绩时重新计算总评、绩点 |
| `trg_score_au_audit` | AFTER | UPDATE | 将修改前后值写入审计表 |
